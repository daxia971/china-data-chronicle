# 中国数据编年史 · 1949 起

一个单页自包含的中国数据聚合站，用图表和时间轴看这片土地从 1949 年至今的变化。

## 模块（9 个，顶部标签切换）

- 🎓 **大学毕业生** 1949–2025（2.1 万 → 1222 万）
- 👶 **人口出生率** 1949–2024（1963 峰值 43‰ → 2023 低点 6.39‰）
- 📝 **高考录取率** 1977 恢复高考起（4.8% → 近 90%）
- 💴 **平均工资** 1952 起（城镇职工年均，445 元 → 12 万+）
- 🌾 **粮食产量** 1949 起（1.1 亿吨 → 7 亿吨）
- 📜 **大事编年** 政策 / 教育 / 计划生育 / 房地产 / AI 分类时间轴，可筛选
- 🩺 **癌症数据** 关键节点新发/死亡病例 + 2022 各癌种拆分
- 💰 **各省 GDP** 2000/2010/2020/2024 前 15 名排行，可切换年份
- 🏠 **房地产变迁** 全国均价走势 + 政策时间轴

## 数据说明

数据综合自国家统计局、教育部、国家癌症中心《中国肿瘤登记年报》、各省统计公报及公开资料。

⚠️ 早期年份（尤其文革期间）与非登记年份（癌症、早期省级 GDP）存在估算，页面内每个模块都有明确的「数据说明」。**仅供趋势参考，请勿作精确引用。**

## 使用

纯静态，直接用浏览器打开 `index.html` 即可（图表库 Chart.js 通过 CDN 加载，需联网）。

技术栈：原生 HTML / CSS / JavaScript + Chart.js。
